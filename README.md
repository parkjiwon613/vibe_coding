# Hana Business Suite — Overseas Remittance

Figma 기반 기업 해외송금 업무 대시보드 프로토타입입니다.

## Stack
- React 18 + TypeScript
- Vite
- lucide-react
- Plain CSS

## 실행
```bash
npm install
npm run dev
```

## 빌드
```bash
npm run build
```

## 화면
1. 통합 대시보드
2. 해외송금 정보 입력
3. 송금 방식 비교
4. 증빙 첨부 및 전자결재 상신
5. 승인관리
6. 거래내역 및 정산 상태
7. 거래 상세 및 SWIFT 비상 전환

데모 데이터이며 실제 은행 송금, OTP, 블록체인, 외부 API와 연결되어 있지 않습니다.
